Giải thích code pipeline LightGBM

Đọc CSV → kiểm tra dữ liệu → chia 5 folds → encode categorical an toàn → train → OOF → submission.

1. Luồng chạy tổng thể

train.csv + test.csv
→
data.py
→
cv.py: 5 folds
→
LightGBM × 5
→
OOF + avg test
→

OOF (out-of-fold) là dự đoán của một dòng train từ model chưa từng train trên chính dòng đó. Vì vậy OOF ROC AUC là score local đáng tin để chọn model và ensemble.

3. src/data.py — đọc và kiểm tra dữ liệu

train = pd.read_csv(data_dir / "train.csv")
test = pd.read_csv(data_dir / "test.csv")
sample_submission = pd.read_csv(data_dir / "sample_submission.csv")

Hàm load_competition_data() đọc ba CSV và chạy các kiểm tra bắt buộc:

if TARGET not in train: raise ValueError(...)
if train[ID_COLUMN].duplicated().any() or test[ID_COLUMN].duplicated().any():
    raise ValueError(...)
if not test[ID_COLUMN].equals(sample_submission[ID_COLUMN]):
    raise ValueError(...)
  • Target chỉ được có ở train.
  • ID phải unique để không thiếu hoặc lặp prediction.
  • Thứ tự test ID phải khớp sample submission.
  • Train/test phải có cùng feature schema; id bị loại khỏi feature list.

Các checks này làm script fail sớm nếu dùng nhầm file, thay vì tạo một submission sai âm thầm.

4. src/cv.py — tạo 5 folds

folds = np.full(len(y), -1, dtype=np.int8)
splitter = StratifiedKFold(n_splits=5, shuffle=True, random_state=seed)
for fold, (_, valid_idx) in enumerate(splitter.split(np.zeros(len(y)), y)):
    folds[valid_idx] = fold

StratifiedKFold giữ tỷ lệ addicted/non-addicted gần bằng nhau trong mỗi fold. shuffle=True tạo split ngẫu nhiên, còn seed cố định giúp tái lập. Output là mảng 0–4, được lưu thành artifacts/folds.csv.

5. src/train_lgbm.py — baseline chính

5.1 Tham số command line

python -m src.train_lgbm --run-name lgbm_raw_v02 --model-seed 42

run-name đặt tên riêng cho artifacts và submission. model-seed dùng khi thử multi-seed.

5.2 Encode categorical theo từng fold chống leakage

encoder = OrdinalEncoder(handle_unknown="use_encoded_value",
                         unknown_value=-1, encoded_missing_value=-1)
train_encoded[CATEGORICAL_COLUMNS] = encoder.fit_transform(train_cat)
valid_encoded[CATEGORICAL_COLUMNS] = encoder.transform(valid_cat)
test_encoded[CATEGORICAL_COLUMNS] = encoder.transform(test_cat)

Encoder chỉ fit trên training rows của fold. Validation/test chỉ transform, nên validation không thể “nhìn” preprocessing học từ chính nó. Missing text được thay bằng __MISSING__; category lạ có mã -1. Numeric missing giữ nguyên để LightGBM xử lý native.

5.3 Cấu hình LightGBM

params = {
  "objective": "binary", "n_estimators": 3000,
  "learning_rate": 0.04, "num_leaves": 63,
  "min_child_samples": 100, "subsample": 0.85,
  "colsample_bytree": 0.85, "reg_lambda": 1.0,
}

n_estimators=3000 là giới hạn trên. early_stopping(150) tự dừng khi AUC validation không tăng trong 150 rounds và prediction dùng best_iteration_.

5.4 Train 5 lần và tạo OOF

for fold in sorted(np.unique(folds)):
    train_mask, valid_mask = folds != fold, folds == fold
    model.fit(x_train, y.loc[train_mask], eval_set=[(x_valid, y.loc[valid_mask])])
    valid_prediction = model.predict_proba(x_valid, ...)[:, 1]
    oof_prediction[valid_mask] = valid_prediction
    test_prediction += model.predict_proba(x_test, ...)[:, 1] / 5

Mỗi vòng train một model với 80% dữ liệu và predict 20% còn lại. Test được predict 5 lần rồi lấy trung bình. Điều này giảm variance so với chỉ train một model.

5.5 Metric, importance và submission

fold_auc = roc_auc_score(y.loc[valid_mask], valid_prediction)
overall_auc = roc_auc_score(y, oof_prediction)

submission = sample_submission.copy()
submission[TARGET] = np.clip(test_prediction, 0.0, 1.0)
submission.to_csv(submission_path, index=False)

fold_auc kiểm tra stability từng fold; overall_auc dùng so sánh model. Copy sample submission giữ ID/order đúng. np.clip đảm bảo output thuộc [0, 1]. Script cũng lưu mean feature importance, JSON metrics và append experiment log.
